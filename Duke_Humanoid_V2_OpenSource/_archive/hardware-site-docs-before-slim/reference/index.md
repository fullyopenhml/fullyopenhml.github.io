# Reference

Lookup material rather than reading material: the team's punch list, the complete
specification table, an index from part number to the page that uses it, the
hardware revision policy, troubleshooting, the questions builders ask first, and
how to cite and licence this work.

<div class="grid cards" markdown>

- **[Open items](todo.md)** — every unresolved gap on this site in one table, with who can close it and whether it blocks the release. Start here if you are working on the robot rather than building one.
- **[Full specifications](full-specifications.md)** — the complete table, with each row's source named, and a list of what is not specified anywhere.
- **[Part index](part-index.md)** — part ID to page, both directions, and why part IDs have to be stable.
- **[Revisions](revisions.md)** — which robot this site documents, and what happens to these pages when the hardware changes.
- **[Troubleshooting](troubleshooting.md)** — symptom to cause, seeded from failures already on record.
- **[FAQ](faq.md)** — what it costs, how long it takes, whether you can build it today.
- **[Citation and licence](citation-and-license.md)** — how to cite, and the three-way licence decision that is still open.

</div>
